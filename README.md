# INDEASA — Infraestructura y Desarrollo

Sitio institucional de INDEASA para presentar servicios de evaluación técnica y recibir solicitudes de proyectos en Guatemala.

## Estructura

- `index.html`: página principal y formulario de consulta.
- `css/`: identidad visual y estilos adaptables.
- `js/wizard.js`: navegación y envío del formulario.
- `netlify.toml`: configuración de publicación y encabezados de seguridad.
- `robots.txt` y `sitemap.xml`: archivos para motores de búsqueda.
- `privacidad.html`: información sobre el uso de los datos del formulario.

## Formulario

El formulario `technical-inquiry` utiliza Netlify Forms. Las solicitudes se registran en el panel del sitio en Netlify. Antes de publicar, debe configurarse una notificación por correo para que INDEASA reciba aviso de cada envío.

## Publicación segura

Los cambios deben prepararse en una rama, comprobarse en una vista previa de Netlify y fusionarse con `main` solamente después de la aprobación.
